# DEVHUB Group Portfolio

DEVHUB Group Portfolio is a WordPress website that introduces four aspiring IT professionals, shares their individual portfolios, and presents the projects they create and explore together. Visitors can start with the group overview, learn about the members, inspect project details, and contact the team.

## Visitor flow

text
Home
 ├── About Us
 ├── Our Members ──> Individual Member Portfolios
 ├── Featured Projects ──> Project Preview Modal
 ├── Our Projects ──> Filter Projects ──> Project Detail Modal
 └── Contact Us ──> Send a Message

The main navigation remains available throughout the site, so visitors can move between Home, About Us, Our Members, Projects, and Contact Us at any time.

## 1. Home — Start with DEVHUB

The homepage introduces the purpose of the group portfolio and gives visitors several ways to continue exploring. Its sections appear in this order:

1. *Hero:* Introduces DEVHUB and offers links to the member portfolios and the project story.
2. *About DEVHUB:* Explains how the members bring different skills together in one shared portfolio.
3. *Meet the members:* Shows a preview of the four members and links to the full directory and individual portfolios.
4. *Our expertise:* Summarizes the team’s practical areas of work: web development, technical writing, systems analysis, and project coordination.
5. *Featured projects:* Highlights selected work. Selecting a project card opens a modal with its preview and details.
6. *Development journey:* Shows the team’s process from planning through analysis, building, and review.
7. *Technologies:* Presents tools used for the portfolio and explored in the team’s projects.
8. *Mission, vision, and values:* Describes the team’s purpose and the principles that guide its work.
9. *Inside each portfolio:* Explains what visitors can find in member portfolios, including introductions, skills, education, and projects.
10. *Explore DEVHUB:* Provides final links to the member portfolios and project collection.

## 2. About Us — Understand the team

The About Us page gives visitors more context about the group and its work. It covers the portfolio’s purpose, objectives, member roles, mission and vision, core values, workflow, team strengths, and reasons for bringing the members’ work together.

Visitors can use its calls to action to continue to the member directory or explore the group’s work.

## 3. Our Members — Meet the people behind the work

Selecting *View Portfolio* opens that member’s individual portfolio. Each portfolio shares member-specific background and work, such as skills, education, projects, and contributions. Visitors can return to the directory or use the main navigation to explore another part of the site.

## 4. Our Projects — Browse the project collection

The Projects page introduces the project archive and lets visitors filter it by *All Projects*, *Group Projects*, or *Individual Projects*. The current collection includes:

1. *DEVHUB Group Portfolio* — The shared WordPress website for the team’s profiles and project work.
2. *Pet Adoption Application* — A mobile application for discovering pets and starting the adoption process. The project lists Laravel and React Native.
3. *PTA Accounting and Membership System* — A system for PTA membership, student and guardian information, contributions, and financial records at Alubijid National Comprehensive High School. The project lists Laravel, Inertia, and React.
4. *ESP32 Experiments* — Individual experiments with ESP32 hardware, sensors, displays, indicators, and IoT connectivity.

Selecting a project card opens a modal containing the available project image, description, technology tags, and project brief. The brief can include the objective, focus, key features or areas explored, technical approach, current status, member contributions, and learning outcomes. Close the modal with its close button, by selecting the backdrop, or by pressing *Escape*.

## 5. Contact Us — Get in touch

The Contact Us page provides contact information, a message form, frequently asked questions, and a closing invitation to connect. Visitors can use the form to send a question or inquiry to the team.

## Team workflow

The portfolio presents the team’s work as a collaborative process:

1. *Plan:* Agree on the purpose, audience, priorities, and responsibilities.
2. *Analyze and organize:* Identify visitor needs, clarify requirements, and organize the information.
3. *Build:* Create the pages and features and bring the project content together.
4. *Review and improve:* Check the content and links, consider different screen sizes, and refine the work using feedback.

Project responsibilities draw on project management, systems analysis, technical writing, and web development.

## Visual style and technologies

The site uses a dark charcoal palette, subtle dotted backgrounds, and orange accents to give its pages a consistent DEVHUB look.

The portfolio itself is built as a custom WordPress theme using PHP, HTML, CSS, and JavaScript. The featured work also represents other technologies: Laravel and React Native in the Pet Adoption Application; Laravel, Inertia, and React in the PTA Accounting and Membership System; and ESP32, sensors, Arduino IDE, C++, and Blynk in individual experiments.
