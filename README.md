# OurSpace Group Portfolio

A custom WordPress portfolio website that brings together the profiles, skills, and work of four aspiring IT professionals. It introduces the team, highlights each member's contribution, and presents collaborative projects and individual experiments in one place.

## Portfolio flow

1. Home — Visitors are welcomed with an introduction to OurSpace and can browse the team's story, members, areas of expertise, featured projects, workflow, and technologies.
2. About Us — Learn about the group's purpose, objectives, values, members' roles, and how the team works together.
3. Our Members — Browse the team and open individual porthfolios to learn about each member's background, skills, and work.
4. Our Projects — Explore project descriptions, goals, technologies, and contributions. The collection includes OurSpace, the PTA Accounting and Membership System, AgriSense, and ESP32 experiments.
5. Contact Us — Send the team a message through the contact form.

The homepage also links directly to the member portfolios and project collection, so visitors can explore in whichever order they prefer.

## Team workflow

The group combines four areas of responsibility:

- Project management — Plans tasks and deadlines and coordinates progress.
- Systems analysis — Identifies user needs and organizes requirements and system flows.
- Technical writing — Prepares clear project descriptions, documentation, and guides.
- Web development — Builds, styles, tests, and improves the website and its features.

For a project, the team moves from planning to analysis, then documentation, and finally building and testing together.

## Technologies

The portfolio uses a custom WordPress theme with HTML, CSS, JavaScript, and PHP. WordPress manages the site and theme templates, while MySQL supports the WordPress installation. Project examples also feature ESP32, sensors, Arduino IDE, and Blynk.
